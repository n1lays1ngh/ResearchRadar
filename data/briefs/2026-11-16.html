ARXIV CS.CL
Computation and Language

Recent research examines how large language model agents handle complex tasks ranging from experimental design and database querying to avoiding hallucinations, managing economic collusion risks, and verifying assumptions during tool use. These studies investigate both the vulnerabilities of agentic systems and novel hybrid architectures designed to improve efficiency and safety.

1
MineralExp: Benchmarking LLM Agents for Experimental Design in Real-World Mineral Exploration
The authors introduce MineralExp, a benchmark that reformulates geochemical experimental design as a hypothesis-based multi-label classification problem using a shared taxonomy across 19 experimental types.
Bing Wang, Mingyang Wang and others · cs.CL, cs.AI, cs.CE  ·  Abstract  ·  PDF  ·  Discuss

Can Mechanistic Interpretability Help Explain LLM Agent Failures? A Case Study on Web Element Hallucination
Researchers applying mechanistic interpretability to web agents find that linear probes can predict and correct action hallucinations, though the underlying computations remain distributed and sensitive to prompt formatting.
Mohamed Aghzal, Mor Geva and others · cs.AI, cs.CL  ·  Abstract  ·  PDF  ·  Discuss
3
LuthorSQL: A One-Pass Text-to-SQL Model as System 1 for a Slower LLM Agent
The authors present LuthorSQL, a non-autoregressive 7B text-to-SQL model acting as a rapid System 1 gate that reduces API costs and queries for a slower LLM agent while maintaining competitive accuracy.
Ibrahim Memon, Armin Karamzade and others · cs.CL, cs.AI, cs.DB  ·  Abstract  ·  PDF  ·  Discuss
4
A Push Down the Mountain: Framing Effects and Internal State Interventions on Collusive Behavior in a Long-Horizon LLM Agent
A market simulation using Gemma 3 12B demonstrates that behavioral framing significantly sways an LLM agent toward collusive behavior, and that internal state interventions can radically alter these participation rates.
Harrison C. Margolin · cs.AI, cs.CL, cs.MA  ·  Abstract  ·  PDF  ·  Discuss

What LLM Agents See and What Users Say
Researchers utilizing presupposition theory find that safe agentic writes require tool lookups that explicitly list or check competing records rather than relying solely on user statements or ambiguous counts.
Yue Zhao, Angela Huyue Zhang and others · cs.AI, cs.CL  ·  Abstract  ·  PDF  ·  Discuss

Recent research addresses energy efficiency across diverse computing domains, introducing frameworks that optimize graph neural network training on memory architectures, synthesize urban energy data, and benchmark code performance. 1
ERGo: Energy-Efficient Hybrid Graph Neural Network Training on Processing-In-Memory Architectures
The authors propose ERGo, a hybrid training framework for processing-in-memory architectures that automatically switches to a parameter-efficient phase using low-rank representations, achieving up to a 3.15x speedup and a 10.5x improvement in energy efficiency.
Pratyush Dhingra, Chibuike E. Ugwu and others · cs.LG  ·  Abstract  ·  PDF  ·  Discuss
2
DySENSE: Dynamic Spatiotemporal ENergy Synthesis and Emulation with Satellite Imagery
The authors introduce DySENSE, a joint multimodal generative AI framework that decouples long-term static urban morphology from short-term dynamic energy consumption to synthesize high-fidelity synthetic energy data using less than 25% labelled data.
Kailai Sun, Zijie Gao and others · cs.CV, cs.AI  ·  Abstract  ·  PDF  ·  Discuss
3
Optimizing Drilling Trajectories in Multi-Material Structures Using Quantum Annealers
The authors present a quantum-hybrid optimization approach utilizing D-Wave's Leap solver to plan energy-efficient drilling trajectories on multi-material structures while accounting for heterogeneous material properties and industrial constraints.
Eneko Osaba and Antonio Rubio-Mateos · cs.AI, cs.ET  ·  Abstract  ·  PDF  ·  Discuss
4
PerfArena: Ranking LLMs by Code Performance
The authors present PERFARENA, an open-source arena that ranks large language models by the execution performance of their generated code, measuring correctness alongside latency, peak memory, and energy consumption across multiple languages.
Rui Rua, Hailemariam Mersha and others · cs.PF, cs.CL, cs.SE · cross-listed  ·  Abstract  ·  PDF  ·  Discuss

Ego2Flow: Benchmarking the Traffic-System Impact of Autonomous Driving on Maps Distilled from Real-World Roads
